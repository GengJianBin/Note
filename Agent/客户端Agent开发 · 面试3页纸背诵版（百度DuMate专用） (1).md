# 客户端Agent开发 · 面试3页纸背诵版（百度DuMate专用）

# 第1页：客户端基础 \+ 架构（必背）

## 1\. 岗位定位（开场白）

客户端Agent = **桌面客户端工程 \+ 本地智能体运行时**。

区别普通客户端：不只是UI交互，具备**本地自主任务规划、工具调用、本地RAG、记忆持久化、沙箱安全、离线执行**，是可自动办公的本地数字员工。

## 2\. Electron 核心原理

- **主进程**：拥有系统权限，负责窗口、文件读写、打包更新、权限、IPC服务。

- **渲染进程**：只做UI、对话流式渲染，无系统权限，保证安全。

- **IPC通信**：渲染进程→主进程→本地Go Agent引擎，是桌面Agent核心通信链路。

## 3\. 桌面流式对话原理

基于 **SSE / WebSocket** 分片流式返回。

流程：长连接建立→逐Token下发→前端缓冲区拼接→节流防抖渲染→断连缓存\+续答→去重防闪。

解决：打字机卡顿、粘包分片、断连丢失、重复请求。

**补充面试考点：SSE vs WebSocket，AI智能体何时必须用WebSocket？**

SSE仅适用于**服务端单向推送**的普通问答场景，以下**双向交互、高频实时、持续联动**的智能体场景必须使用WebSocket：

- **1\. 实时双向交互任务**：智能体边执行任务、边实时回传进度，同时客户端可随时下发暂停、终止、重试、参数修改指令（双向通信），SSE无法实现客户端上行实时指令。

- **2\. 多工具串行/并行联动场景**：文件解析、表格处理、代码执行、批量任务等多步骤工具调用，需要实时双向同步任务状态、实时校验参数、动态调整执行策略。

- **3\. 低延迟高频推送需求**：批量文档解析、实时日志打印、流式进度条渲染，SSE基于HTTP握手开销高，WebSocket长连接零重复握手，延迟更低、稳定性更强。

- **4\. 离线/本地智能体联动场景**：本地模型与客户端实时交互、本地任务状态双向同步，WebSocket支持持续长连接，适配网络波动下的双向续连、状态同步。

**面试一句话总结**：普通流式问答用轻量化SSE，**需要客户端、服务端/本地引擎双向实时通信的复杂Agent自主任务，必须用WebSocket**。

## 4\. 桌面Agent vs Web AI（必考）

- WebAI：纯云端、无本地权限、只能问答、强依赖网络。

- 桌面Agent：**本地文件操作、离线运行、自主多步骤任务、断点续跑、沙箱安全、本地记忆RAG**。

## 5\. DuMate架构（Go\+TS标准架构）

- **TS/Electron**：UI渲染、流式交互、用户操作、IPC请求转发。

- **Go引擎**：Agent运行时、任务调度、ReAct循环、工具队列、本地RAG、持久化。

一句话：**TS管交互，Go管智能体内核**。

# 第2页：Agent核心原理（面试80%分数在这里）

## 1\. Agent ReAct 自主循环（灵魂考点）

标准闭环：**思考 Reason → 行动 Act → 观测 Observe → 循环收尾**

1. LLM分析需求、拆解多步骤任务

2. 输出标准化Function Calling工具指令

3. 客户端本地执行工具（文件/表格/系统操作）

4. 结果回填上下文，再次推理

5. 循环至任务完成/超时终止

客户端独有：**任务状态持久化、防死循环、异步队列、失败重试**。

## 2\. 客户端Function Calling全链路（必背）

1. 客户端预注册工具元数据（功能、参数、格式）

2. 用户问题\+工具描述送入LLM

3. 模型输出JSON结构化调用指令

4. 客户端校验：格式/参数/权限/路径白名单

5. 本地执行系统/文件工具

6. 结果标准化回填对话，继续推理

## 3\. 三层记忆系统（客户端专属）

- **短期记忆**：内存/MMKV，当前对话上下文，滑动窗口截断防溢出。

- **中期记忆**：SQLite持久化任务状态，实现**断点续跑、重启不丢任务**。

- **长期记忆**：本地向量库存历史问答与文档知识，任务自动召回。

## 4\. 客户端本地RAG（必考）

完整流程：本地文档解析 → 清洗 → 切片 → 本地Embedding → 向量入库 → 混合检索 → 重排 → 注入Prompt

核心优化：**BM25关键词\+向量混合检索、本地轻量Embedding、LRU热点缓存、增量更新**

解决问题：模型幻觉、本地私有文档问答、离线知识库能力。

## 5\. Agent Harness 运行时（DuMate重点）

Harness是本地智能体运行时容器，负责：

- ReAct循环调度

- 任务状态机管理（待执行/运行/成功/失败）

- 工具调用队列、并发控制

- 断点持久化、异常重试、超时熔断

- 沙箱安全拦截
