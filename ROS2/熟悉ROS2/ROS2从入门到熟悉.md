# ROS2 从入门到熟悉

## 第一部分：ROS2 入门 → 达到【熟悉】完整学习路线

- 目标：达到简历可写熟悉 ROS2，满足机器人应用开发岗位面试标准（优先 Jazzy / Humble）
- 前置基础：Linux 操作、C++ 基础（rclcpp 为主）、CMake 基础；懂一点点 Git 更佳
- 整体周期：每天 2～3 小时，2.5～3 个月可达到 “熟悉” 水平

1.Ubuntu 基础
2.常用命令：进程查看、权限、ssh、环境变量、软链接
3.学会 vim/nano、进程 htop、网络排查
4.C++ 基础夯实
5.智能指针、类、回调函数、std::thread、chrono 时间
6.工具安装

### 阶段 1 ROS2 基础概念 + 最小节点开发（2～3 周｜核心分水岭）

## 第二部分：ROS2 面试复习提纲（可直接背诵、自测）

- 分为【基础概念、通信机制、TF/URDF、Launch、时间、QoS、Nav2/MoveIt2、工程与排错、ROS1 vs ROS2 对比】

### 一、基础架构【高频】

- 1.ROS2 和 ROS1 最大区别？为什么取消 Master？ ROS1 依靠中心化 Master，单点故障；ROS2 基于 DDS 分布式 P2P 通信，无中心，支持多机、实时性更好。
- 2.什么是 workspace、package、ament_cmake？
- 3.节点、进程、组件节点 Component 区别？
- 4.LifecycleNode 生命周期节点有哪几个状态？优势是什么？ 未配置→配置→非激活→激活→关闭；方便工业机器人启停管理、资源释放。
- 5.rcl、rclcpp、rclcpp_action 三者关系？

### 二、通信模型【重中之重｜必考题】

- Topic / Service / Action 三者对比
- 1.通信模式、同步 / 异步、适用场景
- 2.为什么导航、机械臂运动大量使用 Action？
-   简答：长时间任务，可以中途取消、实时反馈进度；Service 适合瞬时一次性请求。
- 3.自定义 msg/srv/action 完整流程？需要修改哪些文件？
- 4.Parameter 参数系统：节点参数、全局参数、动态参数如何修改？

### 三、时间系统【高频坑题】

- 1.use_sim_time作用？开启仿真时间需要注意什么？
- 2.Header.stamp 应该填系统时间还是仿真时间？
- 3.为什么 TF 经常报查找超时，和时间有很大关系？

### 四、TF2 & URDF/XACRO【必问】

- 1.静态 TF vs 动态 TF 分别什么时候使用？
- 2.TF2 Buffer 缓存作用，缓存时长如何设置？
- 3.TransformException 常见 4 类原因：
  - 坐标系名称拼写错误
  - TF 尚未发布
  - 查询时间超出缓存窗口
  - 仿真时间未同步
- 4.URDF link 和 joint 作用；固定关节 fixed、旋转关节 revolute 区别
- 5.XACRO 相比 URDF 优势：宏定义、变量、复用模型

### 五、Launch 系统

- 1.ros2 run 和 ros2 launch 区别？
- 2.namespace 命名空间、remap 重映射作用，如何实现多机器人并行运行不冲突？
- 3.launch 中如何加载 yaml 参数文件？

### 六、QoS & DDS【高频】

- 1.QoS 是什么？三大核心策略：可靠性、持久性、历史队列
- 2.最经典问题：节点都启动，但是收不到话题消息，优先排查什么？ 优先排查：两端 QoS 不匹配、坐标系名称、时间不同步、namespace
- 3.FastDDS / CycloneDDS 区别，什么时候需要修改 DDS 配置？
- 4.多机通信失败排查步骤：网络连通、DDS 域名、防火墙、端口

### 七、rosbag

- 1.ros2 bag 录制回放原理
- 2.回放时时间错乱如何处理？
- 3.如何只录制指定话题？

### 八、导航 2 / MoveIt2（根据你的方向选择性复习）

- Nav2（移动机器人）
  1.Nav2 行为树 BT 作用
  2.全局规划器、局部规划器分别负责什么
  3.代价地图：静态地图、障碍物层、膨胀层
  4.AMCL 实现机器人定位原理
- MoveIt2（机械臂）
  1.MoveIt2 核心组件：运动规划器、碰撞检测、轨迹执行控制器
  2.规划组 group 定义
  3.笛卡尔规划、关节空间规划区别

### 九、性能与工程优化（进阶面试）

- 1.消息频繁拷贝如何优化？SharedPtr 避免拷贝
- 2.Component 组件节点优势：减少进程间通信开销
- 3.日志分级：Debug/Info/Warn/Error/Fatal 使用场景

### 十、ROS1 vs ROS2 对比简答题（经常出现）

- 1.Master 有无
- 2.通信底层：XMLRPC vs DDS
- 3.启动方式：roslaunch vs python launch
- 4.生命周期、QoS、多机通信原生支持
- 5.编译系统 catkin vs ament

### 十一、故障排查问答（面试官最喜欢用来筛选 “纸上谈兵选手”）

- 1.RViz 看不到机器人模型？
- 2.话题 echo 有数据，RViz 无图像 / 无激光？
- 3.TF 持续报错 TransformException 排查思路
- 4.跨电脑通信，能 ping 通，但是看不到对方节点？
- 5.节点运行一段时间自动卡死、CPU 占用飙升如何定位？
